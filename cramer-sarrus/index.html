Livello 1 · Facile

Cos'è un sistema?

Un sistema lineare è un insieme di equazioni che devono essere vere contemporaneamente. Cerchiamo i valori delle incognite, per esempio x e y.

x + y = 5
x − y = 1

Se sommiamo le due equazioni otteniamo 2x = 6, quindi x = 3. Sostituendo: y = 2. Cramer è un altro modo, molto sistematico, per arrivare allo stesso risultato.

Livello 2 · Determinanti

Prima di Cramer: il determinante 2×2

Prendi quattro numeri disposti in un quadrato. Il determinante si trova facendo il prodotto della diagonale principale meno quello dell'altra diagonale.

| a b |
| c d |   →   ad − bc

Esempio: per la matrice con righe (2, 1) e (3, 4), il determinante è 2·4 − 1·3 = 5.

Livello 3 · Cramer

Risolvere un sistema 2×2 con Cramer

Riprendiamo il sistema iniziale. I coefficienti sono i numeri davanti alle incognite:

1x + 1y = 5
1x − 1y = 1
1. Determinante principale D

D = 1·(−1) − 1·1 = −2

2. Determinante Dx

Sostituisci la colonna di x con i risultati (5, 1).

Dx = 5·(−1) − 1·1 = −6

3. Determinante Dy

Sostituisci la colonna di y con i risultati (5, 1).

Dy = 1·1 − 5·1 = −4

x = Dx / D = −6 / −2 = 3
y = Dy / D = −4 / −2 = 2

Importante: Cramer dà una soluzione unica solo se D ≠ 0. Se D = 0, bisogna usare altri metodi per capire se le soluzioni sono infinite oppure nessuna.

Livello 4 · Tre incognite

La regola di Sarrus per i determinanti 3×3

Con tre incognite (x, y, z), Cramer funziona allo stesso modo. Cambia il calcolo dei determinanti: puoi usare Sarrus, che vale soltanto per matrici 3×3.

| a   b   c |
| d   e   f |
| g   h   i |

D = aei + bfg + cdh − ceg − bdi − afh

Trucco: ricopia le prime due colonne a destra. Somma i tre prodotti sulle diagonali che scendono verso destra e sottrai i tre prodotti sulle diagonali che salgono verso destra.

| 1   0   2 |
| 0   1   1 |
| 1   0   1 |

D = (1·1·1 + 0·1·1 + 2·0·0)
− (2·1·1 + 0·0·1 + 1·1·0)
= 1 − 2 = −1

Per Cramer con tre incognite, calcoli D, Dx, Dy, Dz sostituendo ogni volta la colonna corrispondente con i termini noti. Poi x = Dx/D, y = Dy/D, z = Dz/D.

Verifica quello che hai imparato

1. Quanto vale il determinante di [3, 2; 1, 4]?

3·4 − 2·1 = 10.

2. In Cramer, cosa sostituisci per trovare Dx?

La colonna dei coefficienti di x con i termini noti (i numeri a destra dell'uguale).

3. Sarrus funziona per matrici 4×4?

No. La regola di Sarrus si applica solo alle matrici 3×3.

4. Se il determinante principale è zero?

Non puoi dividere per zero: Cramer non fornisce una soluzione unica. Il sistema può essere impossibile o avere infinite soluzioni.
